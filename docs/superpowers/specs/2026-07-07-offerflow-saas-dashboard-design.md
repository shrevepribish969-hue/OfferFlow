# OfferFlow - 现代 SaaS 风格求职看板与 AI 助手设计规范

本规范定义了求职管理效率工具 **OfferFlow** 的架构与视觉设计。系统采用类似 Apple + Linear + Vercel 的现代极简 SaaS 风格，融合 8px 网格、大量留白与轻量阴影，为求职者提供包含今日待办、求职看板、公司库、日程表、数据分析及右侧常驻 AI 助手的全功能秋招管理工作台。

## 1. 视觉系统与色彩规范
- **默认主题**：浅色模式（背景：`#F8FAFC`，卡片：`#FFFFFF`），支持深色模式切换。
- **主色调 (Accent)**：柔和蓝色 `#4F7CFF`
- **状态色**：
  - 成功 (Success): `#22C55E`
  - 警告 (Warning): `#F59E0B`
  - 危险 (Danger): `#EF4444`
- **圆角规范**：主容器及卡片圆角为 `12px` (对应 Tailwind 的 `rounded-xl`)
- **阴影规范**：使用轻量级阴影 (对应 Tailwind 的 `shadow-sm`)
- **字体系统**：全站使用 `Inter` 字体

## 2. 页面结构与布局
系统采用经典的全高度侧边栏左右布局：
- **左侧侧边栏**：导航菜单（宽度固定），包括：
  1. 🏠 Dashboard
  2. 📄 Applications (看板)
  3. 🏢 Companies (公司)
  4. 📅 Calendar (日历)
  5. 📊 Analytics (数据分析)
  6. ⭐ AI Assistant (AI 问答)
  7. ⚙ Settings (设置)
- **右侧主内容区**：
  - **顶部 Header**：包含 Logo (OfferFlow)、检索框（居中）、`+ New Application` 按钮、消息通知🔔、个人头像😀。
  - **动态子视图 (Tab Views)**：点击左侧菜单切换不同的视图区域，基于单页面架构通过 `div` 的隐藏/显示实现瞬时切换。
  - **右侧常驻 AI 助手侧边栏**：当处于岗位详情页或激活 AI Assistant 功能时展示，为固定宽度。

## 3. 功能模块详细设计

### 3.1 Dashboard (仪表盘)
- **定位**：聚合展现“今天要做什么”。
- **今日指标**：三个小卡片（Today Follow, Interviews, Planned Apply）。
- **今日待办 (Today's Tasks)**：带勾选的代办任务列表（如：Follow up Tencent）。
  - **产生机制**：
    - **自动生成**：系统根据岗位状态（如投递 5 天未更新、面试时间临近等）自动产生待办。
    - **手动录入**：允许用户在界面直接输入自定义任务（如“打印纸质简历”）。
- **周度统计 (Weekly Statistics)**：展示 Apply, Interview, Offer, Reject 核心转化率，并在底部渲染一条具有 Linear 科技感的 SVG 柔和蓝色发光渐变折线图。

### 3.2 Applications (求职看板)
- **看板流程列**：
  `Ready (待准备)` -> `Applied (已投递)` -> `Assessment (测评中)` -> `Written Test (笔试中)` -> `Interview (面试中)` -> `HR (HR面)` -> `Offer (已拿Offer)` -> `Rejected (已拒/感谢信)`
- **卡片拖拽**：支持无缝的 HTML5 卡片拖拽，更改岗位进度状态。
- **卡片展示内容**：公司名、投递岗位、投递渠道、工作城市、投递时间（如 3 days ago）、星级评分（1-5星）。
- **快捷悬浮条**：鼠标 Hover 卡片时出现操作气泡：Open (打开详情)、Edit (编辑)、Reminder (提醒)、Archive (归档)。
- **岗位详情页**：点击卡片后展示左右分栏。左侧为岗位参数（JD、薪资、渠道、投递时间轴等），右侧为**固定不可收起的 AI Assistant**（类似 GitHub Copilot 侧边栏，提供 JD 总结、匹配度评分、模拟面试题、技能差距分析等）。

### 3.3 Companies (公司管理)
- **维度设计**：实行“一司一建”策略。
- **添加机制**：
  - **自动隐式建档**：用户添加或解析岗位卡片时直接输入公司名，若公司库没有，系统在后台无感自动创建并绑定，不中断用户的岗位录入过程。
- **展示内容**：公司介绍、官网、HR联系方式、所属部门、工作地点、官网链接。
- **关联岗位 (Open Positions)**：展示该大厂下你投递的所有子岗位列表。
- **历史时间轴**：记录所有与该公司相关的求职历史大事件。

### 3.4 Calendar (日程表)
- **视图**：Google Calendar 风格的周历视图。
- **事件分类**：用不同的背景色和发光边框标记日程类型（Interview: 蓝色/绿色，Follow Up: 橙色，Deadline: 红色）。
- **交互**：系统自动同步投递岗位的状态关键时间，同时支持双击某天手动增加独立日程。

### 3.5 Analytics (数据分析)
- **定位**：仅展示图表，类似 Mixpanel。
- **图表渲染技术**：完全采用轻量级原生 HTML5 SVG 绘制折线和发光能量条，保证绝对流畅且具备高端极简主义风格。
- **内容**：Apply 趋势图、各渠道（BOSS、官网、内推）响应率统计图、招聘漏斗转化效率。

### 3.6 AI Assistant (AI 问答助手)
- **简历接入**：系统设置页包含“我的个人简历”文本框，LocalStorage 在本地持久保存。
- **功能动作**：侧边栏面板内置一键分析动作按钮：JD Summary, Skill Match, Resume Suggestion, Company Research, Interview Questions, Follow-up Email, Generate Self-introduction。
- **联动行为**：点击任意动作按钮，AI 助手自动拉取简历数据和当前岗位，在右侧对话窗口中直接输出回答。

### 3.7 极速录入与 AI 识别流程 (New Application Flow)
- **触发入口**：点击顶部 Header 的 `+ New Application` 按钮。
- **录入界面**：
  - 提供两个输入区域：`【招聘信息 JD (必填)】` 文本框与 `【官网投递/进度查询链接 (选填)】` URL 输入框。
  - 渐变点击按钮：`[ ⚡ 智能识别并录入 ]`。
- **AI 提取与预览确认**：
  - 前端将粘贴的 JD 发送至大模型 API 进行字段智能提取。
  - 解析成功后，自动渲染出结构化的**预览确认弹窗**，预填好提取出的：公司名称、投递岗位、工作城市、投递日期（默认为今天）、投递状态（默认为 `Applied` 已投递）、跟进天数（默认 5 天，即投递 5 天后提醒追踪）、官网链接、精简 JD 总结。
  - 用户只需确认无误，点击 **确认并保存**，即可一键将该卡片加入看板中，**完全无需手动录入繁琐字段**。
