# OfferFlow 求职助手浏览器扩展

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `extension`。

如果扩展已经加载过，而本目录中的代码刚刚更新，请在扩展卡片上点击一次“重新加载”按钮。

## 使用

1. 点击浏览器工具栏中的 OfferFlow 图标。
2. 点击“编辑我的资料”，填写并保存常用求职信息。
   - 教育背景默认提供两段，可以继续新增或删除。
3. 打开招聘网站的申请表单，再点击“智能识别并填写”。
4. 检查所有字段无误后，由你手动提交。

## 隐私与限制

- 个人资料存放在 `chrome.storage.local`，扩展不会将资料上传到服务器。
- 扩展不会自动提交表单，也不会填写密码、身份证号或上传简历文件。
- 招聘网站字段差异较大，复杂的自定义下拉框可能仍需手动选择。
- “收藏当前职位”功能需要本机运行 OfferFlow 后端（当前为 `localhost:8000`）。
